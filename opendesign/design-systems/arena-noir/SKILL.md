# Arena Noir skill

Product UI system for En Passant chess coach. Dark-first, warm walnut base,
bronze accent ≤10%, felt green isolated to the board. Fraunces display +
Inter body via `next/font`. Tokens: `tokens/colors_and_type.css` (canonical).

Rules: semantic tokens only, never raw hex in components. Motion 150-300ms
`--ease-out-expo`, transform/opacity only, `prefers-reduced-motion` crossfade.
Lucide icons, zero structural emoji. Contrast AA (body 4.5:1).
Board hero, chrome recedes. Badges: engraved seal, no pulse.
